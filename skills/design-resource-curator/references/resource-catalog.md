## Choosing sources

- For visual direction, start with galleries matching the product type and desired mood; for a specific UI area, use a focused gallery such as navigation, CTA, or animation libraries.
- For implementation, check that a component library fits the project's framework, styling, and accessibility needs.
- Use AI design tools or `DESIGN.md` references when they help with the current task, then adapt the result to the project's brand and constraints.
- Choose a small, task-specific subset and explain why each source fits.
