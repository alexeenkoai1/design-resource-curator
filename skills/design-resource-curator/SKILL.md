# Design Resource Curator

For a relevant design task, read [the resource catalog](references/resource-catalog.md) and select only a few sources that fit the product, framework, and visual goal. Do not load the catalog for unrelated work or recommend the whole list.

Use broad galleries to explore visual direction, and focused libraries to solve a specific interface problem. Before recommending an implementation library, check that it fits the project's framework, styling, and accessibility needs. Verify availability, current capabilities, pricing, and terms when those details affect the recommendation. Treat references as inspiration and follow the user's product constraints.
