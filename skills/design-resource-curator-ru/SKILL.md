# Куратор ресурсов для дизайна

Для подходящей дизайн-задачи открой [каталог ресурсов](references/katalog-resursov.md) и выбери только несколько источников, которые подходят продукту, технологиям и визуальной задаче. Не загружай каталог для несвязанных запросов и не рекомендуй весь список.

Используй широкие галереи для поиска визуального направления, а тематические подборки — для решения конкретной задачи интерфейса. Перед рекомендацией библиотеки компонентов проверь её совместимость с технологиями, стилями и требованиями доступности проекта. Проверяй доступность, актуальные возможности, цены и условия использования, если это влияет на рекомендацию. Относись к референсам как к источнику вдохновения и соблюдай требования пользователя к продукту.
