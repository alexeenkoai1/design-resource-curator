# Куратор ресурсов для дизайна

Лёгкий двуязычный скилл для AI-агентов, которые работают над сайтами и интерфейсами продуктов. Он помогает подобрать несколько подходящих референсов, UI-компонентов, примеров анимации и AI-инструментов под конкретную задачу.

**Языки:** [English](README.md) · [Русский](README.ru.md)

В репозитории лежат два независимых скилла, поэтому агенту можно установить только нужный язык:

- **English:** `skills/design-resource-curator/SKILL.md`
- **Русский:** `skills/design-resource-curator-ru/SKILL.md`

Каталог содержит ссылки, а не встроенные плагины. Скилл читает его только для подходящих дизайн-задач и выбирает несколько ресурсов вместо того, чтобы загружать или рекомендовать весь список.

## Установка

Через CLI для скиллов AI-агентов:

```bash
npx skills add alexeenkoai1/design-resource-curator --skill design-resource-curator
```

Русская версия:

```bash
npx skills add alexeenkoai1/design-resource-curator --skill design-resource-curator-ru
```

Также можно искать скиллы командой `npx skills find design resources` или установить выбранный скилл для поддерживаемого кодинг-агента с помощью параметра `--agent`.

## Для чего он нужен

- Поиск визуальных референсов для сайтов, мобильных приложений, лендингов и SaaS-продуктов
- Подбор библиотек UI-компонентов под технологии и задачи проекта
- Поиск примеров навигации, призывов к действию, градиентов и анимаций
- Выбор AI-инструментов и файлов `DESIGN.md`, когда они помогают решить задачу
- Поиск вдохновения, соразмерный конкретной дизайн-задаче

Скилл просит проверять актуальность сайтов, их возможности, цены и условия использования, когда это влияет на рекомендацию. Ни один ресурс из списка не считается обязательным или автоматически одобренным.
